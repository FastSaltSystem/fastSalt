# Project guidance

This repository owns documentation, calculation results, publications, interfaces, and shared decisions. The sibling `fastSaltModels` repository participates in the same Fast Salt System project and keeps its own Git history.

Start with [README.md](README.md) and [STATUS.md](STATUS.md). Consult the relevant design, interface, calculation, and decision records before changing shared assumptions.

- Maintain prose in Markdown and official calculation results in Hurmet Markdown where practical, following `calculations/README.md`.
- Preserve source provenance, historical design revisions, author credits, and original publication files.
- Record cross-component decisions in `decisions/index.md`; update `STATUS.md` when work changes status.
- Distinguish reported research, design targets, provisional assumptions, and visual geometry. Do not infer new research results from graphics.
- Keep generated working outputs out of Git. Preserve named deliverable snapshots deliberately.
- Review and commit each repository separately. Do not discard unrelated changes.
